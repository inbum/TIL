# Suno AI 프롬프트 가이드

## 📌 Context
Suno AI는 텍스트 프롬프트를 기반으로 음악을 생성하는 AI 서비스다. 원하는 음악을 정확하게 생성하려면 스타일(Style of Music) 입력 방식이 중요한데, 단순히 장르명만 입력하면 결과물이 모호해지는 경우가 많다. 이를 해결하기 위한 구조화된 프롬프트 공식을 정리한다.

## ⚙️ Core

### 프롬프트 공식
```
[장르] + [악기] + [분위기] + [보컬 성향]
```

### 예시 프롬프트
```
lo-fi hip hop, mellow piano and vinyl crackle, relaxing and nostalgic, soft female vocals
```
```
epic orchestral, strings and brass, cinematic and intense, no vocals
```
```
K-pop, synth and electric guitar, energetic and bright, high-pitched male vocals
```

### 각 요소 설명
| 요소 | 설명 | 예시 |
|------|------|------|
| 장르 | 음악 스타일의 기본 방향 | lo-fi, jazz, EDM, folk |
| 악기 | 주요 사운드 구성 요소 | piano, violin, synth, acoustic guitar |
| 분위기 | 감정적 톤 또는 에너지 | melancholic, upbeat, dark, dreamy |
| 보컬 성향 | 보컬 유무 및 특성 | no vocals, deep male, soft female |

## 💡 Insight
- **구조화의 효과**: 4가지 요소를 명시하면 Suno AI의 생성 방향이 좁혀져 의도에 가까운 결과물이 나올 확률이 높아진다.
- **보컬 제어가 핵심**: `no vocals` 또는 `instrumental only`를 명시하지 않으면 예상치 않게 보컬이 추가되는 경우가 많으니 주의가 필요하다.
- **분위기 형용사 활용**: Suno는 감정적 형용사에 민감하게 반응하므로 `melancholic`, `euphoric`, `tense` 등 구체적인 단어를 쓸수록 좋다.
- **실무 활용**: 배경음악, 광고 음악, 유튜브 콘텐츠 BGM 등 반복 제작 시 이 공식을 템플릿화하면 일관된 스타일 유지에 유리하다.
