# Suno AI 프롬프트 가이드

## 📌 Context
Suno AI는 텍스트 프롬프트를 기반으로 음악을 생성하는 AI 서비스다. 원하는 음악 스타일을 정확하게 표현하지 못하면 의도와 다른 결과물이 나오기 쉽다. 이를 해결하기 위해 "장르 + 악기 + 분위기 + 보컬 성향" 공식을 활용하면 Style of Music 필드를 체계적으로 작성할 수 있다.

## ⚙️ Core

### 프롬프트 공식
```
[장르] + [악기] + [분위기] + [보컬 성향]
```

### 예시
```
# 예시 1: 감성 팝
Style of Music: acoustic pop, fingerpicked guitar, melancholic, soft female vocals

# 예시 2: 에너지 넘치는 록
Style of Music: alternative rock, distorted electric guitar, energetic, raspy male vocals

# 예시 3: 로파이 힙합
Style of Music: lo-fi hip hop, vinyl crackle, mellow piano, no vocals, nostalgic

# 예시 4: K-POP 스타일
Style of Music: K-pop, synth, upbeat, clean male and female vocals, catchy chorus
```

### 각 요소 설명
| 요소 | 설명 | 예시 |
|------|------|------|
| 장르 | 음악의 큰 장르 | pop, jazz, rock, hip hop, classical |
| 악기 | 주요 사용 악기 | piano, guitar, violin, synthesizer |
| 분위기 | 감정/에너지 톤 | melancholic, upbeat, dark, relaxing |
| 보컬 성향 | 목소리 특성 또는 무보컬 | soft female vocals, no vocals, raspy |

## 💡 Insight
- 공식의 순서보다 **각 요소를 명확히 기술하는 것**이 더 중요하다. Suno는 자연어를 파싱하므로 쉼표로 구분한 키워드 나열이 효과적이다.
- 보컬 유무를 명시하지 않으면 기본적으로 보컬이 포함되는 경향이 있으므로, 인스트루멘털을 원할 경우 `no vocals` 또는 `instrumental`을 반드시 기재해야 한다.
- 지나치게 많은 요소를 조합하면 Suno가 스타일 해석에 혼란을 겪을 수 있으므로, 핵심 키워드 4~6개 이내로 유지하는 것이 좋다.
- Lyrics 필드와 Style 필드를 분리 운용함으로써 가사의 감정과 음악의 분위기를 독립적으로 제어할 수 있다는 점이 Suno의 강점이다.
