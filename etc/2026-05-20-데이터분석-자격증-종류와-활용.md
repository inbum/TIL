# 데이터분석 자격증 종류와 쓸모 정리

## 📌 Context
데이터 직군으로의 진입 또는 역량 강화를 위해 어떤 자격증을 취득해야 하는지 정리할 필요가 생겼다. 국내외 자격증마다 난이도, 인지도, 실무 활용 가능성이 천차만별이므로 목적에 따라 선택 기준을 명확히 해두는 것이 중요하다. 특히 2026년 기준으로 AI/ML, 클라우드, GenAI가 데이터 분야의 핵심 트렌드로 자리잡은 만큼 최신 흐름도 함께 반영하여 정리한다.

### 취득 순서 추천 (목적별)

```text
# 입문자 경로
SQLD → ADsP → 빅데이터분석기사 → Google Data Analytics

# 실무 데이터 사이언티스트 경로
빅데이터분석기사 → IBM Data Science → AWS ML Specialty or Azure Data Scientist

# 클라우드 + MLOps 경로
AWS/GCP/Azure 기초 자격증 → Professional Data Engineer or ML Specialty → Databricks ML Professional

# BI / 시각화 경로
SQLD → Tableau Desktop Specialist → Power BI Data Analyst (Microsoft)
```

- Databricks Certified Generative AI Engineer Associate  → LLM, RAG, LangChain 실무

## 💡 Insight
- **국내 자격증(ADsP, 빅데이터분석기사)** 은 공공기관·대기업 NCS 기반 채용에서 우대 항목으로 인정되나, 실무 역량보다 이론 암기 비중이 높아 포트폴리오를 대체할 수는 없다.
- **글로벌 클라우드 자격증(AWS, GCP, Azure)** 은 실무 프로젝트 경험과 결합될 때 연봉 협상력이 크게 높아진다. 특히 MLOps, 데이터 엔지니어링 직군에서는 사실상 필수 스펙이 되고 있다.
- **2026년 기준 GenAI 관련 자격증** 이 급속도로 생겨나고 있으나, 아직 시장 공신력이 검증되지 않은 것들이 많다. Databricks와 클라우드 3사(AWS/GCP/Azure)가 발급하는 GenAI 자격증은 상대적으로 신뢰도가 높다.
- SQLD는 비전공자도 단기간(1~2개월) 합격 가능하며, SQL 작성 능력이 모든 데이터 직군의 기본 역량임을 감안하면 가성비 최고의 자격증이다.
- 자격증만으로 취업이 보장되지 않으므로, Kaggle 실적·GitHub 포트폴리오·개인 프로젝트와 병행하는 전략이 효과적이다.
